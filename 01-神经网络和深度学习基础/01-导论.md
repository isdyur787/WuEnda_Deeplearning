# 吴恩达 Deep Learning 学习笔记

## 一、 DL 基本概念

Online Note：deeplearning.ai

### 1. 什么是神经网络？Neural Network

- 小圆圈：隐藏神经元
- x：输入特征
- y：输出
- 建立 x 对应 y 的函数映射关系，并且通过监督学习拟合数据

### 2. 是监督学习：Supervised Learning

- 用输入的 x 预测 y

### 3. NN 应用：

- CNN 卷积神经网络（Convolution）：**图像**数据，常常把卷积结构放在神经网络结构中
- 传统 NN：结构化数据（数据库这种每一个特征有清晰定义的数据）房价预测等传统领域
- RNN 循环神经网络（Recurrent）：一些非结构化数据、序列化数据（一维数据、时序数据）：音频、图像、文本、语言
- 其他更复杂、定制化的 NN：自动驾驶领域（Image + Radar）

### 4. DL 发展的需要：（目标：更多的数据、更复杂的神经网络）

- Data
- Computation 运算速度
- Algorithms（算法的提升有助于提高运算速度 eg：把 Sigmoid 变成 ReLU）
